# Anusha Engagement Website — Next.js

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

Push this folder to GitHub, then import the repository into Vercel.
Vercel detects Next.js automatically. No `index.html` is needed.

## Project structure

- `app/page.tsx` — website page
- `app/layout.tsx` — metadata/layout
- `app/globals.css` — design/styles
- `app/Petals.tsx` — falling-petal animation
- `public/images/` — engagement photos
